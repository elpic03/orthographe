# Phrases de contexte du bloc, pour les mots qu'on ne peut pas distinguer à l'oreille.
# Format : mot | phrase
# Une ligne qui commence par * = phrase « pour comprendre le sens » : pas lue automatiquement,
#   seulement avec le bouton Phrase. Sans * = phrase « pour distinguer », lue après le mot au 1er essai.
# Le « mot » doit être EXACTEMENT le nom du fichier audio du mot (sans .mp3).
# Pour chaque ligne, générer le fichier audio de la phrase dans CE dossier (phrases),
# sous le même nom que le mot. Exemple : listes/13/phrases/mangé.mp3
un dépit | Il boude par dépit après la défaite.
un débat | La classe fait un débat sur les devoirs.
un contrat | Le joueur signe un contrat avec l'équipe.

un habit | Il met son habit de neige pour jouer dehors.
un profit | Il vend de la limonade pour faire un profit.
un récit | Le professeur lit un récit d'aventure.
